1. Python object model foundations

Everything in OOP rests on one fact: in Python everything is an object. Integers, functions, classes, modules, even None are objects with an identity, a type, and a value.

1.1 Names, objects and references

A variable is a name bound to an object, not a box holding a value. Assignment never copies; it binds.

a = [1, 2, 3]
b = a            # same object, two names
b.append(4)
print(a)         # the change is visible through both names
print(a is b)    # identity check
print(a == [1, 2, 3, 4])  # equality check (value)

[1, 2, 3, 4]
True
True

Rule: is compares identity (same object). == compares value (calls __eq__). Use is only for singletons such as None, True, False.

1.2 Mutable vs immutable

Immutable: int, float, complex, bool, str, bytes, tuple, frozenset, range. Mutable: list, dict, set, bytearray, and most user-defined objects.

def add_item(item, bucket=[]):   # classic bug: default evaluated ONCE at def time

1.6 Truthiness, equality and hashing basics

Falsy values: None, False, 0, 0.0, "", [], {}, set(), () and any object whose __bool__ returns False or __len__ returns 0. Objects used as dict keys or set members must be hashable: a == b implies hash(a) == hash(b), and the hash must not change while the object lives in the container.

3.2 Properties

@property lets you expose an attribute while keeping validation and computed values behind the scenes.

class Temperature:
    def __init__(self, celsius):
        self.celsius = celsius            # goes through the setter

    @property
    def celsius(self):
        return self._celsius

    @celsius.setter
    def celsius(self, value):
        if value < -273.15:
            raise ValueError("below absolute zero")
        self._celsius = value

    @celsius.deleter
    def celsius(self):
        del self._celsius

    @property
    def fahrenheit(self):                 # read-only computed property
        return self._celsius * 9 / 5 + 32

t = Temperature(25)
print(t.fahrenheit)
try:
    t.celsius = -300
except ValueError as e:
    print(e)

77.0
below absolute zero

Start with plain attributes; upgrade to a property later without changing callers. That is why Python needs no getter/setter boilerplate.

3.3 Controlling attribute access

class Strict:
    def __getattr__(self, name):          # only called when normal lookup FAILS
        return f"<missing {name}>"
    def __setattr__(self, name, value):   # called on EVERY assignment
        if name.startswith("_"):
            raise AttributeError("no private attrs")
        super().__setattr__(name, value)
    def __delattr__(self, name):
        print("deleting", name)
        super().__delattr__(name)

s = Strict()
s.a = 1
print(s.a, s.zzz)
del s.a

1 <missing zzz>
deleting a

__getattribute__ runs on every access (use with care; always delegate to super().__getattribute__ to avoid infinite recursion).

3.4 Read-only and immutable objects

Use properties without setters, @dataclass(frozen=True), NamedTuple, or __slots__ plus __setattr__ guards. Immutable objects are hashable, thread-safe and easier to reason about.

4. Inheritance

4.1 Single inheritance and super()

class Animal:
    def __init__(self, name):
        self.name = name

4.2 Kinds of inheritance

Single (one parent), multilevel (A to B to C), hierarchical (one parent, many children), multiple (several parents) and hybrid (mix). All are expressible with the same syntax.

class A: pass
class B(A): pass          # single
class C(B): pass          # multilevel
class D(A): pass          # hierarchical with B
class E(B, D): pass       # multiple/hybrid
print([k.__name__ for k in E.__mro__])

['E', 'B', 'D', 'A', 'object']

4.3 Method Resolution Order (C3 linearization)

The MRO is the order in which Python searches classes. C3 guarantees children precede parents and the order of bases is preserved. View it with Class.__mro__ or Class.mro().

class Base:
    def who(self): return "Base"
class Left(Base):
    def who(self): return "Left > " + super().who()
class Right(Base):
    def who(self): return "Right > " + super().who()
class Child(Left, Right):
    def who(self): return "Child > " + super().who()

print(Child().who())
print([c.__name__ for c in Child.__mro__])

Child > Left > Right > Base
['Child', 'Left', 'Right', 'Base', 'object']

super() does not mean "the parent"; it means "the next class in the MRO of the instance's type". That is what makes cooperative multiple inheritance work (the diamond problem is resolved; Base runs once).

4.5 Mixins

A mixin is a small class that adds one behavior and is not meant to stand alone.

4.6 Composition over inheritance

"Is-a" means inherit; "has-a" means compose. Inheritance couples subclasses to parent internals; composition is flexible.

class Engine:
    def start(self): return "engine on"
class Car:
    def __init__(self, engine):
        self.engine = engine          # has-a
    def start(self):
        return self.engine.start()    # delegation
print(Car(Engine()).start())

4.7 Overriding, extending, and the Liskov principle

Override to change behavior, call super() to extend it. Subclasses must honour the parent's contract (Liskov Substitution): anywhere a parent is expected, a child must work without surprising callers. The classic violation is Square(Rectangle) with a setter that changes both sides.

import math
class Vec:
    def __init__(self, x, y): self.x, self.y = x, y
    def __repr__(self): return f"Vec({self.x}, {self.y})"
    def __add__(self, o):
        if not isinstance(o, Vec): return NotImplemented
        return Vec(self.x + o.x, self.y + o.y)
    def __mul__(self, k):
        if not isinstance(k, (int, float)): return NotImplemented
        return Vec(self.x * k, self.y * k)

    def __neg__(self): return Vec(-self.x, -self.y)
    def __abs__(self): return math.hypot(self.x, self.y)

        self.x += o.x; self.y += o.y
        return self
    def __bool__(self): return bool(abs(self))
    def __eq__(self, o): return isinstance(o, Vec) and (self.x, self.y) == (o.x, o.y)
    def __hash__(self): return hash((self.x, self.y))

7.3 Comparison

__eq__ __ne__ __lt__ __le__ __gt__ __ge__. Define __eq__ and one ordering method, then let functools.total_ordering fill the rest. Defining __eq__ without __hash__ makes the class unhashable.

from functools import total_ordering

@total_ordering
class Version:
    def __init__(self, s): self.parts = tuple(map(int, s.split(".")))
    def __eq__(self, o): return self.parts == o.parts
    def __lt__(self, o): return self.parts < o.parts
    def __hash__(self): return hash(self.parts)
    def __repr__(self): return "v" + ".".join(map(str, self.parts))

print(sorted([Version("1.10"), Version("1.2"), Version("1.9.1")]))
print(Version("2.0") >= Version("1.9"))

9.1 The descriptor protocol

An object that defines __get__, __set__ or __delete__ and lives as a class attribute is a descriptor. With __set__ or __delete__ it is a data descriptor (wins over the instance __dict__); with only __get__ it is a non-data descriptor (instance __dict__ wins).

class Positive:
    def __set_name__(self, owner, name):      # called at class creation
        self.private = "_" + name
    def __get__(self, obj, objtype=None):
        if obj is None:                        # accessed on the class
            return self
        return getattr(obj, self.private)
    def __set__(self, obj, value):
        if value <= 0:
            raise ValueError(f"{self.private[1:]} must be positive")
        setattr(obj, self.private, value)

class Product:
    price = Positive()
    qty = Positive()
    def __init__(self, price, qty):
        self.price, self.qty = price, qty

import asyncio
from contextlib import asynccontextmanager

async def ticker(n):
    for i in range(n):
        await asyncio.sleep(0.01)
        yield i                                  # async generator

@asynccontextmanager
async def resource():
    print("open"); yield "res"; print("close")

async def worker(q, sem, out):
    while True:
        item = await q.get()
        async with sem:                          # limit concurrency
            out.append(item * 2)
        q.task_done()

async def main():
    async for i in ticker(3):
        print("tick", i)
    async with resource() as r:
        print(r)
    q, sem, out = asyncio.Queue(), asyncio.Semaphore(2), []
    ws = [asyncio.create_task(worker(q, sem, out)) for _ in range(3)]
    for i in range(5): q.put_nowait(i)
    await q.join()
    for w in ws: w.cancel()
    print(sorted(out))

15.9 Common pitfalls

Forgetting await (you get a coroutine object, not a result), running blocking calls in the loop, shared mutable state without locks in threads, creating tasks without keeping a reference (they can be garbage collected), and deadlocks from inconsistent lock ordering. 24. Interview questions with answers

What is the difference between is and ==?

is tests identity (same object in memory); == tests value equality through __eq__.

What is the difference between a class method, static method and instance method?

Instance methods receive the instance (self), class methods receive the class (cls) and suit alternative constructors, static methods receive nothing extra and are plain functions namespaced in the class.

What does super() do in multiple inheritance?

It returns a proxy to the next class in the instance type's MRO, not simply the parent. This lets every class in a diamond run exactly once when all use super() cooperatively.

How is the MRO computed?

With the C3 linearization algorithm: each class precedes its parents and the left-to-right order of bases is preserved. Inspect it with cls.__mro__.

__str__ versus __repr__?

__repr__ is unambiguous and aimed at developers (ideally evaluable); __str__ is readable output for users. str() falls back to __repr__ if __str__ is missing.

Why does defining __eq__ make my class unhashable?

Python sets __hash__ to None when you define __eq__ without __hash__, because equal objects must hash equally. Define __hash__ from immutable fields to restore hashability.

What are __slots__ and when would you use them?

They replace the per-instance __dict__ with fixed storage. Use them for millions of small objects to save memory and to forbid stray attributes.

Explain descriptors in one paragraph.

A descriptor is a class attribute whose type defines __get__, __set__ or __delete__. Python consults it during attribute access. Properties, methods, classmethod, staticmethod and __slots__ are all descriptors. Data descriptors take priority over the instance dictionary; non-data descriptors do not.

What is a metaclass?

The class of a class. type is the default. It controls class creation (__new__, __init__, __prepare__) and instantiation (__call__). Prefer class decorators or __init_subclass__ when they suffice.

What is the difference between a decorator and a closure?

A closure is a function that captures variables of its enclosing scope. A decorator is a callable that wraps another callable and is usually implemented with a closure.

Iterator versus iterable versus generator?

An iterable can produce an iterator through __iter__. An iterator implements __next__. A generator is an iterator created by a function with yield or by a generator expression.

What is the GIL and how do you work around it?

A lock allowing one thread to run Python bytecode at a time in standard CPython. Use processes for CPU-bound work, threads or asyncio for I/O-bound work, or native extensions that release the lock. A free-threaded build exists from 3.13.

threading vs multiprocessing vs asyncio?

Threads share memory and suit blocking I/O; processes give true CPU parallelism with separate memory and pickling cost; asyncio runs many cooperative tasks on one thread and needs non-blocking libraries.

How does Python manage memory?

Private heap, reference counting for immediate release, a generational cyclic garbage collector, and small-object allocators (pymalloc). weakref avoids keeping objects alive.

Shallow copy vs deep copy?

Shallow copies the container but shares nested objects; deep copy recursively duplicates everything (copy.deepcopy), and handles cycles.

What is the mutable default argument trap?

Defaults are evaluated once at function definition, so a mutable default is shared across calls. Use None and create the object inside, or field(default_factory=...) in dataclasses.

Abstract class vs interface vs Protocol?

ABCs declare abstract methods and enforce them at instantiation (nominal typing). Python has no interface keyword; ABCs with only abstract methods or Protocols (structural typing) fill the role.

What is duck typing?

Judging an object by the methods it supports rather than its declared class.

How do @property, @cached_property and @functools.lru_cache differ?

property computes on every access; cached_property computes once per instance and stores the result; lru_cache memoizes function results by arguments (arguments must be hashable).

What is __name__ == "__main__" for?

It is true only when a file runs as a script, letting the same file act as an importable module and a program.

What is the difference between deepcopy of an object and pickling it?

Both can duplicate an object graph. Pickle serialises to bytes for storage or transport (and executes arbitrary code on load, so never unpickle untrusted data).

How do you make a class iterable, a context manager, callable, sortable?

__iter__, __enter__/__exit__, __call__, and __lt__ (with total_ordering) respectively.

What changed in recent Python versions that every developer should know?

Pattern matching (3.10), exception groups and TaskGroup (3.11), PEP 695 generics and the type statement (3.12), the experimental free-threaded and JIT builds (3.13), and deferred annotation evaluation (3.14).

26.2 One-line reminders

  • Attribute lookup: data descriptor, instance dict, non-data descriptor or class attribute, __getattr__.
  • super() follows the MRO of the instance's class.
  • Define __eq__ and __hash__ together; return NotImplemented for unsupported operands.
  • Never use mutable defaults. Use default_factory.
  • Decorators: use functools.wraps; extra arguments need one more nesting level.
  • Generators are lazy, single-pass iterators.
  • Always use with for resources; always encoding="utf-8" for text files.
  • CPU-bound: processes. I/O-bound: asyncio or threads.
  • Prefer composition, small interfaces, dependency injection, and tests.
  • Measure before optimising.
